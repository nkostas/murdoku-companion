New / Edit — User Guide

1. Basic information

Enter a puzzle title. Pick a 6×6, 9×9 or 16×16 preset, or enter your own Rows, Columns and Suspects (up to 52). Press Apply to generate suspects and redistribute their colors across the full color spectrum. Presets only fill in the fields; you can edit them first.

The letter X is excluded. Up to 22 suspects, V always represents the Victim. With more than 22 suspects, neither V nor X is used.

2. Image

Paste an image URL or select a local image. A local image is embedded in the saved puzzle. If the title is blank, the image filename may be used as the title. Remove image clears the background.

3. Editor modes

  • Perspective: Drag the TL, TR, BR and BL corner handles to the photographed grid corners and choose Rectify image. Use Reset corners to try again.
  • Calibration: Align the grid by dragging its four edges in the preview.
  • Blocked cells: Left click a free cell to block it; click a blocked cell to unblock it. Left drag repeats the first cell's action throughout the drag. Right click does nothing. Use Clear all blocked cells to reset the blocks.

4. Tools panel

Drag the right edge of the editor tools panel to resize it independently from the Play suspect sidebar. The width is remembered.

Set Marker & symbol size in Play, below the Note Symbols list (70%–150%).

5. Finish

Save & Play saves the setup and returns to the board. Cancel discards unsaved edits. New Puzzle starts a blank setup. Changing the grid size or suspect IDs can clear existing play progress, so Export a backup beforehand.

Play — User Guide

Select a suspect or note symbol on the left, then mark possibilities on the puzzle grid. The app helps you track deductions; it does not solve the puzzle automatically.

1. Puzzle grid

  • Left click / drag: Add or remove candidate positions for the selected suspect or note symbol. The first cell determines whether dragging adds or removes marks.
  • Right click / drag: Add or remove a global X. An X marks a cell as impossible for every suspect.
  • Long left press: Place or remove the selected suspect or symbol. The rest of its row and column become automatically unavailable.
  • Eraser: Enable it, then left click or drag to clear marks, manual X or a placement in each cell. Right click continues to control X.

2. Suspect cards

  • Left click: Select suspect; the selected suspect's indications are emphasized on the board. Other suspects' indications remain visible.
  • Right click: Cycle ribbon type (none / single / double / thick). A suspect without a ribbon starts with the last-used ribbon style and color.
  • Ctrl + click: Cycle ribbon color (white, black, red, yellow, green, blue, orange, purple).
  • Shift + click: Cycle gender (none / male / female).
  • Long left press: Change the suspect's letter.

Press a suspect's letter key (A–Z) to select it. Redistribute colors changes suspect colors without resetting the puzzle.

3. Note symbols & progress

Triangle, circle, square and star are personal note symbols; they may be marked and placed, but they do not count as suspects when you Check the puzzle.

Undo / Redo affects board actions only, not gender or ribbon changes. Clear selected suspect removes the selected suspect's marks. Reset progress clears play progress after confirmation.

4. Puzzle & display

Available positions counts cells remaining after blocked cells, manual and automatic X marks, and placements. Candidate marks do not reduce this count. Check verifies that all suspects have been placed consistently with row, column and blocked-cell rules, not against an official solution.

Use Coordinates and Dark / Light view to adjust the interface. Dark view does not change the puzzle image. Use Marker & symbol size below Note Symbols to resize grid annotations immediately (70%–150%).

5. Export & Import

Progress is saved locally when browser storage is available. Export downloads the puzzle and its progress in one JSON file named Puzzle Name_YYYYMMDD_HHMM.json. Import restores them on the same or another device.
