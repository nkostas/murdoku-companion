Murdoku Companion — v0.3.46

Open index.html in a modern browser, or use the online application:
https://nkostas.github.io/murdoku-companion/

For full New / Edit and Play instructions, see README.md or use the Help buttons inside the app.

Changes in v0.3.46:
- Fixed Rectify image error caused by an obsolete syncInsetInputs() call.
- Rectification now continues to update the image, reset insets, and return to Calibration.

Changes in v0.3.45:
- Load example in the New / Edit header opens the included The Treasure Hunt 24x24 puzzle after confirmation; Save & Play commits the example, Cancel preserves the original puzzle.
- In puzzles without an image, blocked cells are solid dark gray in Edit and Play. When an image is set, the previous translucent appearance is preserved.

Changes in v0.3.44:
- Removed Left, Top, Right and Bottom percentage input fields in Edit; grid edges remain draggable.
- Moved Marker & symbol size to Play, below Note Symbols, with immediate updates and saved value.
- Editor modes are vertical, with context-specific buttons on the right of each mode.
- Drag the right edge of the editor tools panel to resize it; the editor width is remembered independently.

The full guide and AI disclosure are in README.md.

No server, database or account required. Export JSON to back up or transfer your puzzle and progress.
