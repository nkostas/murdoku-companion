Murdoku Companion — version 0.3.42

Murdoku General v0.3.42

Changes:
- Edit > Blocked cells: left click on a free cell adds a block; left click on a blocked cell removes it.
- Drag uses the action chosen by the first cell for all subsequent cells: paint or erase.
- Right click / right drag no longer change blocked cells.
- All previous features are preserved.

Murdoku General v0.3.41

Changes:
- Undo and Redo now affect only grid/board actions: candidate marks, X marks, and suspect/note-symbol placements.
- Changes to suspect gender, ribbon style, and ribbon color are NOT added to Undo/Redo history.
- Undoing a board action leaves suspect annotations and the currently selected suspect untouched.
- Ribbon style and ribbon color now use a shared, persistent brush. Right-click an unribboned suspect to copy the last-used ribbon style/color, then continue right-clicking to cycle its ribbon thickness.
- Ctrl+click changes ribbon color and updates the shared color for later ribbons.
- Import/Export saves the shared ribbon brush while older saves remain supported.

Open index.html locally to play (no server required).
